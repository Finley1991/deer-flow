# DeepHourAI Documentation

DeepHourAI is a framework for building and operating agent systems. It gives you a runtime harness for composing agents with memory, tools, skills, sandboxes, and subagents, and it also provides an application layer that turns those capabilities into a usable product experience.

This documentation is organized around those two parts:

- **DeepHourAI Harness**: the core SDK and runtime layer for building your own agent system.
- **DeepHourAI App**: a reference application built on top of the Harness for deployment, operations, and end-user workflows.

If you want to understand how DeepHourAI works, start with the Introduction. If you want to build on the core runtime, go to the Harness docs. If you want to deploy and use DeepHourAI as an application, go to the App docs.

## Documentation structure

The Introduction section helps you build the right mental model before you look at implementation details.

- **What is DeepHourAI** explains what DeepHourAI is and what problems it is designed to solve.
- **Why DeepHourAI** explains the motivation behind the project.
- **Core Concepts** introduces the concepts that appear across the documentation.
- **Harness vs App** explains the relationship between the runtime layer and the application layer.

### DeepHourAI Harness

The Harness section is the core of the technical documentation. It is written for developers who want to build their own DeepHourAI-based system.

- **Quick Start** shows how to create your first harness with the core DeepHourAI API.
- **Design Principles** explains the architectural ideas behind the Harness.
- **Configuration** covers the main configuration surface of the SDK/runtime.
- **Memory**, **Tools**, **Skills**, and **Sandbox** explain the major system capabilities separately.
- **Customization** shows how to adapt DeepHourAI to your own product requirements.
